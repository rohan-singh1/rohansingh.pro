Selected UI work

Tools built inside Unreal Engine, where the interface is the product.

01 · Unreal Editor tool

Layout Visualizer

An editor tool for laying out building assemblies such as doors, windows and fixtures on a snapping grid, so layouts can be composed and adjusted visually instead of by hand.

  • Assembly catalog to drag components onto the layout
  • Alignment and snapping controls with precise position adjustment
  • Version 2.0 keeps everything from v1 and adds new features, shown in the video
Unreal EditorEditor toolUI design
02 · Unreal Engine · Azure Digital Twins

Digital Twins Explorer

An in-engine interface for working with Azure Digital Twins: browse model hierarchies, author models, and inspect live twins without leaving Unreal.

  • Searchable model tree with inheritance (TwinBase → TwinObject → Sensor…)
  • Model editor that shows local and inherited properties alongside the generated JSON
  • Twin inspector with live values, such as a weather twin's temperature, humidity and wind
  • Relationship tools: fetch, highlight and find orphaned twins
